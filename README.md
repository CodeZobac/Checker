# Checker

Every software change begins with a conversation. **Checker** is the record of that conversation: an app that keeps the exact prompts sent to AI coding agents alongside a clear summary of what changed and which files were touched.

The story continues across every developer and every task. Checker helps teams understand the work being done, evaluate the quality of the prompts that guided it, and measure how many tokens were spent along the way. Over time, those records reveal which instructions, structures, and keywords consistently lead to better code with fewer tokens.

In that way, Checker becomes more than an activity log. It is a growing map of effective collaboration between developers and AI coding agents—capturing the prompts that worked, the changes they produced, and the lessons that can improve the next task.

The app will be built with a **Next.js** frontend and a **Rust** backend powered by **Axum** and **ZeroClaw**.
